# 面向报文处理的编译器与 IR 设计

这是一套以 p4.c3 为案例的中文教材，目标是让读者能够设计报文中间表示、理解布局规划，并判断低复制代码生成是否正确。默认读者能阅读 C/C3，理解结构体、数组和指针，不要求已有编译器开发经验。

教材编写基线：2026-10-11。项目范围以 [v0 子集](../v0-subset.md)和[项目目标](../project-vision.md)为依据。当前已有 AST、子集检查和参考解释器；本文提出的 IR、分析和后端接口是教学设计，不代表仓库已实现，也不构成新的项目规范。

## 全书约定

- 区间统一写成半开区间 `[start, end)`，长度为 `end - start`。
- 除非特别说明，偏移与长度以字节为单位；源语言字段宽度以 bit 为单位。
- `A`、`B`、`C` 是逻辑 header 实例；payload 是 parser 消费终点之后的剩余输入。
- 数值布局例子假设缓冲区连续、可写、容量足够，且未修改字段；真实实现必须检查前提。
- 无语言标注的代码块是教学伪代码，不保证能被 P4、C3 或当前工具直接执行。
- 教学中的操作名和数据结构名不是已存在的 API。SSA、一般重排等内容用于理解原理，不要求 v0 立即实现。
